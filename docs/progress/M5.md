## What changed during M5 (all committed with tests)
- **Question jobs.** Aggregate questions run as jobs with server-applied filters.
- **Server-filled selections.** `select_all_late_open` resolves seller groups server side, and Order targets select themselves. The model never enumerates IDs.
- **Validator.** Thousands-separated copies of evidence integers are accepted; it found a false rejection in the first live job. Empty selections are rejected instead of crashing the validator. The worker fails a job with `VALIDATOR_ERROR` rather than leaving it active.
- **Credentials.** Expired AWS credentials count as confirmed no-generation failures, and the runner survives per-job errors.
- **Token budget.** The token estimate tightened to 3 characters per token, after an analyst input of 4,083 tokens exceeded the 4,000 budget.
- **Prompts.** Compact output, then minimal whitespace (a "single line" instruction caused malformed JSON from Nova 2 Lite).
- **Runner precheck.** The runner refuses to start when gold users have active jobs.
- **Test isolation.** Test cleanup no longer touches evaluation jobs.
- **Fault injection.** Opt-in worker fault injection for drills (`OPS_FAULT_INJECT`, via `deploy.py release --fault`).
