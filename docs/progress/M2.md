## Design notes
- **One authorization predicate.** `VISIBLE_ORDER` in `backend/ops/queries/scope.py` sits in the first CTE or WHERE clause of every order query. It applies before joins, aggregates, the graph, and serialization. Scope is reloaded from the database on every request.
- **Late-open predicate.** It is written in an index-friendly form (`estimated_at < date(as_of)`), and the 30-day cap turns it into a range scan on `orders(batch_id, estimated_at, order_id)`.
- **Evidence.** Every tool result carries typed evidence references, including `is_synthetic` for scenario data, and a canonical SHA-256 evidence hash. `check_case_eligibility` compares the submitted snapshot hash against a freshly computed one.
- **API.** Logs record only the route template, status, and latency. Uvicorn's access log is disabled because paths carry IDs. Validation errors list field names, never submitted values.
- **New migration `0003`.** The worker role gets read-only access to cases and proposals for the existing-case check. It still cannot insert cases or modify proposals.
- **`ops seed-users --mode local`** is implemented. `--mode aws` waits for Cognito (M4.5). The M4 gate re-verifies the grants.
