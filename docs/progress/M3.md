## Also covered
- **Idempotent submission.** The same key and request return the existing job; a different request returns 409; there is one outbox row per job. HTTP returns 202, then 200, then 409.
- **Submission rules.** Only operators submit. Viewers and reviewers get 403. A hidden target gets 404, and its ID is not echoed.
- **Daily cap.** At 100 admitted calls the stage fails before any provider call (`test_daily_cap_blocks_admission`).
- **Grant revoked mid job.** The job is `blocked / SCOPE_CHANGED` with no paid call (`test_scope_change_mid_job_blocks`). Saved results are withheld on read when scope changes.
- **Invalid JSON.** The job fails with one call and no repair.
- **Retries.** A confirmed throttle is retried exactly once. The Bedrock client is built with `total_max_attempts = 1`.
- **Token budget.** The analyst input for the busiest Olist seller fits the 4,000-token budget after bounding.
- **Job reads.** Only the owner can read a job; ETags give 304 responses.
