S3, ACM, CloudWatch Logs, Route 53, and Bedrock model listing work. CDK cannot bootstrap or deploy until these restrictions lift.
2. **Domain not provided.** `configs/deploy.yaml` → `domain` is null. An ISSUED ACM certificate for it in us-east-1 is also needed. Preflight finds the certificate automatically.
3. **`OPS_AWS_ACCOUNT_ID` must be set** in the deploy shell, so preflight can confirm the intended account. It is deliberately not committed.
