## Incident during deployment (resolved)
- **What happened.** The first migration task failed: the role-bootstrap SQL lacked a `text` cast. Its error message (SQLAlchemy exception text) wrote the `ops_import` database password into CloudWatch Logs.
- **Response.** The log stream was deleted, a search found no remaining matching events, and the `ontology-ops/db/ops_import` secret was rotated before any role existed.
- **Prevention.** All engines now use `hide_parameters=True` and the CLI reports only the exception type. Tests: `tests/unit/test_secret_hygiene.py`.
- **Exposure.** The password was never valid against the database: the role had not been created, and it was created later with the rotated value.
